# Code of Conduct

Glider contributors are expected to be respectful, constructive, and
professional. Harassment, discrimination, threats, doxxing, sexualized
attention, and deliberate disruption are not acceptable.

Report conduct concerns privately to the repository maintainer through the
same private channel used for security reports. Include relevant context and
links, and avoid sharing private personal information unnecessarily.

Maintainers may remove comments, close discussions, or restrict participation
when behavior violates this policy. Retaliation against a good-faith report
is not acceptable.
